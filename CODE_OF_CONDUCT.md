# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind. Disagreements are
about code and evidence, not people.

Report violations privately to the maintainer via the contact in [SECURITY.md](SECURITY.md).
Reports are handled confidentially.
